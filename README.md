# 甲作实验室 · Nailform Lab

一个可长期迭代的 DIY 美甲设计工作台。当前版本支持甲型、长度、颜色、质感、图案和饰品的逐指组合，以及本地方案保存、参考报价和护理提醒。

## 本地启动

```bash
npm install
npm run dev
```

当前同目录的鱼缸项目占用 `3000` 时，本项目会自动使用 `http://localhost:3001/`。

## 验证

```bash
npm run lint
npm test
```
