# 甲作实验室（Nailform Lab）项目方案

## 1. 产品定位

甲作实验室是一款面向美甲爱好者和美甲师的 DIY 设计工具。用户可以在做甲前，先组合甲型、长度、颜色、质感、图案与饰品，实时预览整手效果，并获得价格、耗时、耐用度和护理建议。

它不是预约平台，也不是换装游戏。核心价值是把“脑海中的款式”变成可沟通、可保存、可复用的设计方案，降低用户和美甲师之间的信息差。

## 2. 核心用户

- 想自己搭配款式、但不熟悉美甲术语的消费者
- 需要与顾客快速确认方案的美甲师
- 想沉淀作品模板与材料库的工作室
- 进行穿戴甲定制的商家

## 3. 核心体验

1. 选择甲型与长度，立即看到手部整体比例变化。
2. 逐指或一键全手设置主色、质感、图案和饰品。
3. 通过接近真实材质的光泽、透度和反射预览设计。
4. 自动生成价格、耗时、耐用性与护理建议。
5. 本地保存方案，后续可扩展分享图、预约单与材料清单。

## 4. 版本规划

### V0.1：交互原型（当前版本）

- 4 种甲型、3 档长度
- 6 种颜色、5 种质感、4 种图案、4 种点缀
- 单指编辑与应用全部
- 参考价格、预计时长与风险提示
- 浏览器本地保存和恢复
- 桌面与移动端自适应

### V0.2：专业设计能力

- 自定义取色与品牌色号库
- 左右手独立设计、撤销/重做、图层顺序
- 更多法式边、贴纸、手绘纹理与饰品
- 方案导出图片、分享链接与二维码
- 材料用量和美甲师施工步骤

### V0.3：高仿真 3D

- 真实手模、指甲曲率和皮肤材质
- 环境灯、柔光箱与户外光照预设
- 猫眼磁粉、镜面粉、果冻胶的物理材质
- 手部旋转、缩放和不同肤色
- 移动端性能分级与低配回退

这一阶段适合让 K3 专注实现 Three.js/WebGPU 的手部网格、指甲曲面和材质系统，产品状态与业务规则仍由主项目统一管理。

### V1.0：商业闭环

- 用户账户与云端作品集
- 美甲师材料库、报价单与预约单
- 穿戴甲尺寸采集和订单
- 门店模板、品牌皮肤与多人协作

## 5. 技术方案

- 前端：React 19、TypeScript、vinext
- 当前预览：CSS 2.5D，零重型 3D 依赖，保证首屏与移动端性能
- 3D 阶段：Three.js / React Three Fiber，GLTF/Draco 模型与 KTX2 纹理
- 状态：当前使用 React state + localStorage；商业化阶段升级为服务端账户与数据库
- 测试：服务端渲染断言、类型检查、ESLint、构建测试；3D 阶段增加视觉回归与设备性能基线

## 6. 关键指标

- 完成一套设计的比例与平均耗时
- 单次设计使用的功能数量
- 方案保存/分享率
- 从方案到预约或下单的转化率
- 美甲师二次修改次数与沟通时长
